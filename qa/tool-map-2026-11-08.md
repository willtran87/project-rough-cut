# Optional tools on the course map

The expanded map now pairs letter markers with a compact list of the pond/range circuit switches and maze/release cart timers. The list describes their duration/noise tradeoffs, shows live countdowns, and distinguishes ready, waiting, ringing and spent states. Ignored timers return to ready using the existing refund behavior. It explicitly says the course continues while the map is open.

This is read-only planning information from authoritative interaction state. It neither selects a new navigation target nor reveals hidden Joe/ghost positions. It appears only on the expanded map, remains hidden during practice and pause, and uses existing UI polling/canvas overlay. No new scene geometry, lighting, texture or shader. Existing required-objective guidance, route choices, movement and AI are unchanged.
